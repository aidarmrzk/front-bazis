# Заметки и задачи

Обновление существующего Nuxt 4 приложения: сохраняются Composition API,
Pinia, доменные типы Note / TodoItem и формат сохранённых заметок версии 1.
Новый репозиторий имеет самостоятельную историю.

## Границы модулей

- `app/lib`: типы, валидация и миграция схемы, патчи, сессия ввода,
  отложенное сохранение черновика и клавиатурные команды.
- `app/stores/notes.ts`: сохранённые заметки, синхронизация вкладок,
  обработка недоступного хранилища. Изменения редактора сюда не попадают до сохранения.
- `app/composables`: связывают редактор, маршрутизацию, стор и диалоги.
- `app/components`: карточки, поля, панель действий и модальные окна.
- `app/pages`: две компактные композиции, `/` и `/notes/[id]`;
  `new` зарезервирован для создания. Ключ страницы равен полному маршруту.

История содержит типизированные патчи title, todo-text, todo-completed,
insert и remove. Вставка/удаление хранят только один пункт с позицией.
Ввод группируется в пределах поля по идентификатору, blur или паузе 650 мс.
Undo/redo сохраняют максимум 50 шагов, новая правка сразу очищает redo.

Сохранённые заметки пишутся в localStorage только при явных CRUD-командах.
Перед командой перечитывается актуальная база, чтобы не затереть другие заметки.
Черновики хранятся отдельно в sessionStorage: вкладки не делят незавершённый ввод.
Запись через 350 мс, синхронное завершение при pagehide и выходе из редактора.
Сохранение и отмена останавливают таймер и очищают черновик и историю.
Ошибки доступа/квоты показываются пользователю, не выдаются за успешное сохранение.

Пустые поля не сохраняются: требуется заголовок и текст каждого добавленного пункта.
Список задач может быть пустым. Пробелы по краям удаляются при сохранении.
Удалённая в другой вкладке заметка остаётся доступна как локальный черновик:
пользователь может сохранить её копию или выйти. Конфликт обновления не перезаписывает
чужую версию: предлагается сохранить свою копию.

## Интерфейс

Светлая рабочая поверхность #f5f6fa, белые карточки #ffffff, текст #242838,
фиолетовый акцент #5947c7, вторичный текст #60677a, ошибка #b32638.
Системный Segoe UI, выравнивание по левому краю, заголовки 32/24 px, текст 16 px.
Узкая навигация слева, рабочая область справа; на телефоне навигация сверху.
Прогресс задач читается в карточке. Все действия имеют текстовые подписи.
Модальное окно именовано заголовком, блокирует фон, удерживает фокус,
закрывается по Escape и возвращает фокус инициатору.

## Проверки

Vitest: патчи, лимит, атомарность, группировка и сброс истории; CRUD,
повреждённые данные, миграция, квота, гонки между вкладками, черновики,
клавиатурные команды и фокус. Дополнительно проверяются типы и production-сборка.
